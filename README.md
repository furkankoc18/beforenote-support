# BeforeNote public support pages

This folder contains public BeforeNote marketing, support and privacy pages. It is
the separate public GitHub Pages repository named `beforenote-support`.
Do not copy the iOS project, user records, screenshots, or identity documents into
that repository.

The root page and the English/Turkish rental-car guides link to the live App Store
listing. The three images in `assets/` are public marketing screenshots made from
fictional sample records, not user photos. Support and privacy URLs remain unchanged.
